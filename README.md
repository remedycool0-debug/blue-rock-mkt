# BlueRock Marketing

Sitio web corporativo para BlueRock, una agencia de marketing B2B enfocada en estrategia, posicionamiento, contenido, performance y automatización comercial.

## Stack

- Astro
- TypeScript
- Tailwind CSS
- GSAP y ScrollTrigger

## Desarrollo local

```bash
npm install
npm run dev
```

## Comprobación y build

```bash
npm run check
npm run build
```

La versión actual del formulario de diagnóstico es demostrativa: no envía ni almacena información.
